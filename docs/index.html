2026 CORE ARCHITECTURE

Engineered for AI CLI Agents & Heavy Linux Workloads

Every subsystem in DevBox is purpose-built to eliminate the crashes, keyboard corruption, and memory leaks that plague traditional Android terminal emulators.

⚡
TERMINAL ENGINE

2D Matrix VT100/XTerm PTY & Differential IME Bridge

Unlike line-based text views, TerminalGridBuffer maintains a true dual-buffer (Primary + ?1049h Alternate Screen) character matrix with 24-bit TrueColor, regional scrolling (DECSTBM), and a custom differential Android InputConnection. Typing inside Google Antigravity CLI (agy), Claude Code, or Neovim never suffers from predictive keyboard composition bugs or stuck cursors.

/dev/ptmx JNI ?1049h Alt-Buffer TIOCSWINSZ Auto-Resize 60FPS Throttling
🛡️
MEMORY GUARD

Zero-Orphan Process Reaper

Every shell session is tagged with a unique DEVBOX_SESSION_ID in /proc/[pid]/environ. Closing a session executes an escalating SIGHUP → SIGTERM → SIGKILL sweep across the process tree while protecting active foreground AI agents.
